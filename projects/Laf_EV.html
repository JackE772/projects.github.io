PROJECT / ELECTRONICS

FPGA Arcade system

This project is an FPGA-based arcade system that allows users to play classic arcade games on a custom-built hardware platform. The system is designed to provide a retro gaming experience with modern enhancements, including improved graphics and sound capabilities.

Tools:Verilog, Vivado, VGA

Overview

This progect involved designing and implementing several classic arcade games on an FPGA platform. The system includes a VGA output for video display and user input through buttons. The project required knowledge of digital logic design, FPGA programming, and hardware interfacing.

My Contribution

  • Desgined top level architecture
  • Created the FPGA design and implemented the logic.
  • Debugged the design and resolved issues.

Testing and Results

The design was tested on the FPGA development board in two ways. The first was through wavform simulations in vivado to verify the logic and timing of the design. The second was through testing on the actual hardware to ensure that the system functioned as expected and that the games were playable.
